# Scripts

Helper scripts for setting up and running NUVEXA AI.

## Windows

| Script | Purpose |
|--------|---------|
| `SETUP.bat` | Install Python dependencies |
| `RUN_NUVEXA.bat` | Launch the Streamlit app |

## Linux / macOS

| Script | Purpose |
|--------|---------|
| `setup.sh` | Install Python dependencies |
| `run.sh` | Launch the Streamlit app |

### Usage

```bash
# First-time setup
bash scripts/setup.sh

# Run the application
bash scripts/run.sh
```

> **Note:** Make scripts executable if needed: `chmod +x scripts/*.sh`
